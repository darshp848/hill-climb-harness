Will configure project hill-climb-sims, region us-central1, repository hill-climb, bucket gs://hill-climb-sims-results, worker/builder accounts, Dream/Claude secret containers and a 50 USD budget alert.
Project creation and billing linking are manual. Existing secret versions are never rotated.
DRY RUN: gcloud services enable batch.googleapis.com compute.googleapis.com artifactregistry.googleapis.com cloudbuild.googleapis.com secretmanager.googleapis.com storage.googleapis.com billingbudgets.googleapis.com logging.googleapis.com iam.googleapis.com --project hill-climb-sims --quiet
If missing:
DRY RUN: gcloud artifacts repositories create hill-climb --location us-central1 --repository-format=docker --project hill-climb-sims --quiet
If missing:
DRY RUN: gcloud storage buckets create gs://hill-climb-sims-results --location us-central1 --uniform-bucket-level-access --public-access-prevention --project hill-climb-sims --quiet
If missing:
DRY RUN: gcloud iam service-accounts create hill-climb-worker --project hill-climb-sims --quiet
If missing:
DRY RUN: gcloud iam service-accounts create hill-climb-builder --project hill-climb-sims --quiet
DRY RUN: gcloud projects add-iam-policy-binding hill-climb-sims --member serviceAccount:hill-climb-worker@hill-climb-sims.iam.gserviceaccount.com --role roles/batch.agentReporter --project hill-climb-sims --quiet
DRY RUN: gcloud projects add-iam-policy-binding hill-climb-sims --member serviceAccount:hill-climb-worker@hill-climb-sims.iam.gserviceaccount.com --role roles/logging.logWriter --project hill-climb-sims --quiet
DRY RUN: gcloud projects add-iam-policy-binding hill-climb-sims --member serviceAccount:hill-climb-builder@hill-climb-sims.iam.gserviceaccount.com --role roles/logging.logWriter --project hill-climb-sims --quiet
DRY RUN: gcloud artifacts repositories add-iam-policy-binding hill-climb --location us-central1 --member serviceAccount:hill-climb-worker@hill-climb-sims.iam.gserviceaccount.com --role roles/artifactregistry.reader --project hill-climb-sims --quiet
DRY RUN: gcloud artifacts repositories add-iam-policy-binding hill-climb --location us-central1 --member serviceAccount:hill-climb-builder@hill-climb-sims.iam.gserviceaccount.com --role roles/artifactregistry.writer --project hill-climb-sims --quiet
DRY RUN: gcloud storage buckets add-iam-policy-binding gs://hill-climb-sims-results --member serviceAccount:hill-climb-worker@hill-climb-sims.iam.gserviceaccount.com --role roles/storage.objectCreator --project hill-climb-sims --quiet
DRY RUN: gcloud storage buckets add-iam-policy-binding gs://hill-climb-sims-results --member serviceAccount:hill-climb-builder@hill-climb-sims.iam.gserviceaccount.com --role roles/storage.objectViewer --project hill-climb-sims --quiet
If missing:
DRY RUN: gcloud secrets create dream-api-key --replication-policy=automatic --project hill-climb-sims --quiet
DRY RUN: gcloud secrets add-iam-policy-binding dream-api-key --member serviceAccount:hill-climb-worker@hill-climb-sims.iam.gserviceaccount.com --role roles/secretmanager.secretAccessor --project hill-climb-sims --quiet
If missing:
DRY RUN: gcloud secrets create anthropic-api-key --replication-policy=automatic --project hill-climb-sims --quiet
DRY RUN: gcloud secrets add-iam-policy-binding anthropic-api-key --member serviceAccount:hill-climb-worker@hill-climb-sims.iam.gserviceaccount.com --role roles/secretmanager.secretAccessor --project hill-climb-sims --quiet
DRY RUN: gcloud billing budgets list --billing-account <BILLING_ACCOUNT_ID> --filter=displayName=hill-climb-sims-monthly '--format=value(name)' --project hill-climb-sims --quiet
DRY RUN: gcloud billing budgets create --billing-account <BILLING_ACCOUNT_ID> --display-name hill-climb-sims-monthly --budget-amount 50USD --filter-projects projects/hill-climb-sims --threshold-rule=percent=0.5 --threshold-rule=percent=0.9 --threshold-rule=percent=1.0 --project hill-climb-sims --quiet
DRY RUN: upload Dream key via stdin only if no enabled version; grant current user actAs on both accounts.
Budget alerts notify billing IAM recipients; they do not cap spending.
