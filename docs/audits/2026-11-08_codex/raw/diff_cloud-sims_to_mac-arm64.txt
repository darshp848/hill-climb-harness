+# Making the local decision code fast (notes for whoever sets up the match laptop)
+
+The match runs on an Apple Silicon MacBook Air: 4 performance + 4 efficiency cores, no fan. Everything below runs on
+that laptop, every frame or every tick, with no API call. The remote calls (Dream-1, the Claude/OpenRouter monitor)
+are network-bound and not covered here.
+
+## What runs locally, and how often
+
+| Piece | File | Rate in a match | Work per call |
+|---|---|---|---|
+| Live guard | `harness/live_guard.py` | 10 Hz x 2 wrist cameras (`--live-guard`) | `TableDetector.guard` on each new wrist JPEG |
+| Fast loop (if `fast:` in the plan; no shipped plan has it) | `harness/fastloop.py` | 20 Hz x 2 wrists | the same guard + observer + state-space step |
+| Per-poll guard | `runner.fast_guard` | every `check_every_s` (3 s in v4) | the same guard on the poll's frames |
+| Monitor request | `MonitorVerifier._build` | each check (~every 3-6 s, `parallel: 2`) | boxes on 3 frames (`annotate_frames`), stitched history grid, base64, stage text |

+## Rules for any further optimisation
+
+1. **Exact or not at all.** A guard verdict that changes is a behaviour change in a safety stop. Every change to
+   `detect.py` must keep `tests/test_guard_equivalence.py` green: it compares the guard verdict, every box and every
+   annotated JPEG with `tests/_detect_reference.py` (the detector the match was tuned with) on
+   `tests/data/guard_frames`. Run it on more frames with
+   `HARNESS_GUARD_FRAMES=<folder> python -m pytest tests/test_guard_equivalence.py`.
+   If you do want different behaviour (a smaller frame, a crop), that is a re-tune: change
+   `plans/table_colors.yaml` or the reference on purpose, re-run the table photos, and say so in the commit.
+2. **Measure on the Mac, sustained.** A fanless Air is fast for 30 s and slower after a few minutes.
+   `python tools/mac_bench.py --sustained 300` shows p95 per 30 s window and `pmset -g therm`.
+3. **Vectorise and do less, don't add threads.** numpy and Pillow release the GIL in their C loops, but there are
+   only 4 performance cores and the guard, the fast loop, the monitor build and the HTTP threads already share them.
+   `harness/perf.py` caps BLAS/OpenMP to one thread; keep it that way.
+4. **Never touch what Dream-1 sees or is told.** The detector only reads frames; prompts stay byte for byte.
+
+## What was done (8 Nov, branch mac-arm64)
+
+All exact (equivalence test above, plus 201 more real and sim frames):
+
+- **Morphology without scipy's iterated loops.** `binary_closing(iterations=2)` is four whole-array shifts each
+  way (`_close2`); `binary_fill_holes` is one labelling of the background (`_fill_holes`). Both are checked against
+  scipy on random masks of every shape in `test_close_and_fill_are_scipys`.
+- **Crop before labelling.** Fill and label run on the box around the mask plus one pixel (`_crop`); a colour with
+  a handful of pixels costs microseconds instead of a full-frame label.
+- **No per-blob full-image scans.** The old loop did `np.nonzero(lab == i)` over the whole image for every blob; now
+  each blob is read inside its `find_objects` box, and a box too small to pass `min_frac` is skipped unread.
+- **The guard asks only its own question.** `TableDetector._held` runs only the colours that can trip it, skips
+  blobs too small to be held or centred outside `grip_roi` before the shape test, and stops at the first held ball.
+- **uint8 HSV planes.** No int16 copy; bounds every pixel passes (black's hue and saturation) build no array.
+- **Stitch tile cache.** The stage-start and history frames come back in every check; resized tiles are cached by
+  digest (32 tiles, ~8 MB), so a check decodes and resizes only its new frame.
+- **State-space thresholds built once.** `StateSpace.decide` rebuilt five arrays from Python lists every tick;
+  with K = 1000 weight sets (offline hill-climb sweeps) a step went from 246 us to 46 us, decisions identical.
+
+## What is left, best first
+
+1. **Share frames and verdicts between the live guard and the fast loop.** With both on, each has its own
+   `LiveFrames` and runs the detector on its own fetch of the same cameras, so the detector work doubles. One
+   frame source feeding both, plus a verdict memo keyed by the frame's SHA-1 (both loops already hash each frame),
+   halves it. Behaviour note: the fast loop would then see the guard's frames, not its own fetch 0-50 ms later.
+2. **Ask the station for 640 px frames in the live guard** (`/frame/<cam>.jpg?w=640`, as `FrameSource` already does).
+   Fewer bytes over Wi-Fi and a smaller decode. The pixels differ slightly from a draft-mode decode of the full
+   frame, so this is a re-tune: re-check `plans/table_colors.yaml` on real wrist frames first.
+3. **HSV conversion** (~2 ms of the ~5 ms guard on x86; decode ~1 ms, the rest is per-colour masks and labels). Pillow's RGB->HSV is a per-pixel float routine. A
+   256^3 lookup table built once from Pillow itself would be exact by construction (50 MB) but may not beat Pillow
+   on memory bandwidth; measure on the Air. Do not re-derive the HSV formula in numpy: rounding differs.
+4. **Do the guard only where a held ball can be.** A held ball's blob must be centred in `grip_roi`, but it can
+   extend outside it, so cropping the image before closing is not exact. Only as a re-tune.
+5. **Fast loop at 10 Hz instead of 20** when it is in shadow mode: it logs only, so half the rate halves its cost.
+   That is a plan setting (`fast.rate_hz`), not code.
+6. **State-space model.** Already microseconds a tick; `Observer._update` loops over a dict in Python, which is
+   fine at K = 1. For offline sweeps over many weight sets, batch over K (the `StateSpace` already is) rather than
+   over runs in Python.
+

+def bench(fn, *, seconds: float, min_iters: int = 20) -> dict[str, float]:
+    """Runs fn() back to back for `seconds` (at least min_iters times) after a short warm-up."""
+    for _ in range(3):
+        fn()
+    ms: list[float] = []
+    c0, w0 = time.process_time(), time.perf_counter()

+        t = time.perf_counter()
+        fn()
+        ms.append(1000 * (time.perf_counter() - t))
+    return _stats(ms, time.process_time() - c0, time.perf_counter() - w0)

+class Cycle:
+    """Endless supply of recorded frames. Each one is made unique (a counter after the JPEG's end marker, which
+    decoders ignore), as a live camera's frames are, so no digest-keyed cache can reuse an earlier result."""

+        self.frames, self.i = frames, 0

+    def next(self) -> bytes:
+        j = self.frames[self.i % len(self.frames)]
+        self.i += 1
+        return j + self.i.to_bytes(8, "little")

+def sustained(args, det: TableDetector, wrists: list[bytes], others: list[bytes]) -> list[dict]:
+    """Match load (or flat out) for args.sustained seconds; one row per args.window seconds."""
+    stop = threading.Event()
+    lock = threading.Lock()
+    rec: dict[str, list[float]] = {"guard": [], "tick": []}
+    over = {"n": 0}
+
+    def timed_guard(frames):
+        t = time.perf_counter()
+        r = det.guard(frames)
+        with lock:
+            rec["guard"].append(1000 * (time.perf_counter() - t))
+        return r
+
+    threads: list[threading.Thread] = []
+    if args.sustained_mode == "match":
+        cyc_g, cyc_f = Cycle(wrists), Cycle(wrists[::-1])
+
+        def periodic(period: float, body, record_tick: bool = False):
+            def run():
+                while not stop.is_set():
+                    t = time.perf_counter()
+                    body()
+                    took = time.perf_counter() - t
+                    with lock:
+                        if record_tick:
+                            rec["tick"].append(1000 * took)
+                        if took > period:
+                            over["n"] += 1
+                    stop.wait(max(0.0, period - took))
+            return run
+        fl = FastLoop(frames=lambda: {"wrist_l": cyc_f.next(), "wrist_r": cyc_f.next()}, guard_judge=timed_guard,
+                      grippers=lambda: {"right": {"opening": 0.1}})
+        fl.attempt_start("pick_ball", 1e9, None, guarded=True)
+
+        def live_guard_tick():
+            for role in ("wrist_l", "wrist_r"):
+                timed_guard({role: cyc_g.next()})
+        plan = load_plan(ROOT / "plans" / "hill_climb_v4.yaml")
+        mv = MonitorVerifier(plan, transport=lambda payload: {"content": []})
+        mv.annotator = det.annotate_frames
+        stage = next(st for st in plan.stages if plan.guard is not None and plan.guard.covers(st.name))
+        cyc_m, t_el = Cycle(wrists), [0.0]
+
+        def monitor_tick():
+            t_el[0] += 3.0
+            mv._build(stage, {"scene": others[0], "wrist_l": cyc_m.next(), "wrist_r": cyc_m.next()}, t_el[0])
+        threads = [threading.Thread(target=periodic(0.1, live_guard_tick), daemon=True),
+                   threading.Thread(target=periodic(0.05, fl.step, True), daemon=True),
+                   threading.Thread(target=periodic(3.0, monitor_tick), daemon=True)]
+    else:
+        def flat_out(k: int):
+            cyc = Cycle(wrists[k:] + wrists[:k])
+            while not stop.is_set():
+                timed_guard({"wrist_r": cyc.next()})
+        threads = [threading.Thread(target=flat_out, args=(k,), daemon=True) for k in range(args.threads)]
+
+    rows: list[dict] = []
+    t_end = time.perf_counter() + args.sustained
+    for th in threads:
+        th.start()
+    print(f"\nsustained {args.sustained_mode} load, {args.sustained:.0f} s"
+          f"{'' if args.sustained_mode == 'match' else f' on {args.threads} threads'}:")
+    print(f"{'window':>8} {'guard p50':>10} {'guard p95':>10} {'guards/s':>9} {'tick p95':>9} {'overruns':>9} "
+          f"{'cpu %':>7}  thermal")
+    w = 0
+    while time.perf_counter() < t_end:
+        c0, w0 = time.process_time(), time.perf_counter()
+        stop.wait(min(args.window, t_end - w0))
+        with lock:
+            g, tk, ov = rec["guard"], rec["tick"], over["n"]
+            rec["guard"], rec["tick"], over["n"] = [], [], 0
+        wall = time.perf_counter() - w0
+        row = {"t_s": round((w + 1) * args.window), "guards": len(g), "guards_per_s": len(g) / wall,
+               "guard_p50_ms": float(np.percentile(g, 50)) if g else None,
+               "guard_p95_ms": float(np.percentile(g, 95)) if g else None,
+               "tick_p95_ms": float(np.percentile(tk, 95)) if tk else None, "overruns": ov,
+               "cpu_pct": 100.0 * (time.process_time() - c0) / wall, "thermal": thermal_state()}
+        rows.append(row)
+        f = lambda v: f"{v:10.2f}" if v is not None else f"{'-':>10}"  # noqa: E731
+        print(f"{row['t_s']:>7}s {f(row['guard_p50_ms'])} {f(row['guard_p95_ms'])} {row['guards_per_s']:9.1f} "
+              f"{f(row['tick_p95_ms'])[1:]} {ov:9d} {row['cpu_pct']:7.1f}  {row['thermal'] or ''}")
+        w += 1
+    stop.set()
+    for th in threads:
+        th.join(timeout=2.0)
+    return rows
+

+def thermal_state() -> str | None:
+    """macOS: `pmset -g therm` (CPU_Speed_Limit 100 = not throttled). None elsewhere."""
+    if sys.platform != "darwin":
+        return None
+    try:
+        out = subprocess.run(["pmset", "-g", "therm"], capture_output=True, text=True, timeout=2).stdout
+    except (OSError, subprocess.SubprocessError):
+        return None
+    vals = [ln.strip().replace(" ", "") for ln in out.splitlines() if "=" in ln]
+    return ",".join(vals) or "no warning"
+
+
+def machine() -> dict[str, str | int | None]:
+    info: dict[str, str | int | None] = {"host": socket.gethostname(), "platform": platform.platform(),
+                                         "machine": platform.machine(), "python": platform.python_version(),
+                                         "cpus": os.cpu_count(), "numpy": np.__version__,
+                                         "pillow": Image.__version__}
+    try:
+        import scipy
+        info["scipy"] = scipy.__version__
+    except ImportError:
+        info["scipy"] = None
+    if sys.platform == "darwin":
+        for key in ("machdep.cpu.brand_string", "hw.perflevel0.physicalcpu", "hw.perflevel1.physicalcpu"):
+            try:
+                info[key] = subprocess.run(["sysctl", "-n", key], capture_output=True, text=True,
+                                           timeout=2).stdout.strip()
+            except (OSError, subprocess.SubprocessError):
+                pass
+    else:
+        info["cpu"] = platform.processor()
+    info["threads_env"] = {k: os.environ.get(k) for k in ("OMP_NUM_THREADS", "OPENBLAS_NUM_THREADS",
+                                                          "VECLIB_MAXIMUM_THREADS", "MKL_NUM_THREADS")}
+    return info
+
+
+def main(argv: list[str] | None = None) -> int:
+    ap = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
+    ap.add_argument("--frames", type=Path, default=ROOT / "tests" / "data" / "guard_frames",
+                    help="folder of recorded JPEGs (names with 'wrist' are wrist views)")
+    ap.add_argument("--config", type=Path, default=ROOT / "plans" / "table_colors.yaml")
+    ap.add_argument("--seconds", type=float, default=2.0, help="time per component")
+    ap.add_argument("--sustained", type=float, default=0.0, help="seconds of sustained load (300 = 5 min)")
+    ap.add_argument("--sustained-mode", choices=("match", "max"), default="match")
+    ap.add_argument("--threads", type=int, default=4, help="--sustained-mode max: guard threads")
+    ap.add_argument("--window", type=float, default=30.0, help="sustained: seconds per row")
+    ap.add_argument("--no-ref", action="store_true", help="skip the pre-optimisation detector")
+    ap.add_argument("--label", default="", help="free text saved in the JSON (e.g. 'on battery, lid open')")
+    ap.add_argument("--out", type=Path, default=None)
+    args = ap.parse_args(argv)
+
+    wrists, others = _load_frames(args.frames)
+    det = TableDetector.from_file(args.config)
+    ref = None if args.no_ref else _reference_detector(args.config)
+    info = machine()
+    print(f"{info['host']}  {info['platform']}  {info['machine']}  python {info['python']}  "
+          f"numpy {info['numpy']}  pillow {info['pillow']}  scipy {info['scipy']}")
+    print(f"{len(wrists)} wrist frames, {len(others)} other frames from {args.frames}")
+    t0 = time.time()
+    comp = components(args, det, ref, wrists, others)
+    print(f"\n{'component':<14} {'p50 ms':>9} {'p95 ms':>9} {'max ms':>9} {'cpu %':>7} {'n':>7}")
+    for name, r in comp.items():
+        print(f"{name:<14} {r['p50_ms']:9.3f} {r['p95_ms']:9.3f} {r['max_ms']:9.3f} {r['cpu_pct']:7.1f} {r['n']:7d}")
+    if "guard_ref" in comp:
+        print(f"\nguard speedup over the pre-optimisation detector: "
+              f"p50 x{comp['guard_ref']['p50_ms'] / comp['guard']['p50_ms']:.2f}, "
+              f"p95 x{comp['guard_ref']['p95_ms'] / comp['guard']['p95_ms']:.2f}")
+    # What the match asks of the guard: 10 Hz live guard + 20 Hz fast loop, two wrists each = 60 frames/s worst case
+    load = 60 * comp["guard"]["mean_ms"] / 1000
+    print(f"match guard load (60 wrist frames/s): ~{100 * load:.0f}% of one core")
+    rows = sustained(args, det, wrists, others) if args.sustained > 0 else []
+    result = {"machine": info, "label": args.label, "started": time.strftime("%Y-%m-%dT%H:%M:%S%z",
+                                                                             time.localtime(t0)),
+              "frames": str(args.frames), "components": comp, "match_guard_core_fraction": load,
+              "sustained": {"mode": args.sustained_mode, "seconds": args.sustained, "rows": rows} if rows else None}
+    out = args.out or ROOT / "bench_results" / (f"mac_bench_{info['host']}_"
+                                                f"{time.strftime('%Y%m%dT%H%M%S', time.localtime(t0))}.json")
+    out.parent.mkdir(parents=True, exist_ok=True)
+    out.write_text(json.dumps(result, indent=1) + "\n", encoding="utf-8")
+    print(f"\nwrote {out}")
+    return 0
+
+
+if __name__ == "__main__":
+    raise SystemExit(main())
