+# Five-minute Hill Climb supervisor
+
+## Usage
+
+Run the sprint plan for unplug and stack, or the full plan to exercise the optional plug and balls. Use a mock station and a scripted monitor for scheduling tests.
+
+```python
+plan = load_plan("plans/hill_climb_full.yaml")
+result = Runner(plan, station, frames, {"monitor": monitor}, log).run()
+abandoned = [stage.name for stage in result.stages if stage.abandoned]
+```
+
+The match plans use 300 seconds, with the last five reserved for requesting stop. The runner starts its clock after preflight. Match procedure still needs to align this start with the organizer's go signal. A designated team member can call stop.
+
+## Shape
+
+`Plan.match: MatchRules | None` enables the match clock and validates the named unplug and stack gates. Required stages run in plan order and halt on exhaustion. `Stage.stage_budget_s` caps total work, including retries and resets. `on_fail: abandon` marks an optional stage. Its `reserve_after_s` protects time for later stages. A dependent optional stage only runs after its prerequisite passes. The runner records abandonment separately from success and continues to the next eligible stage.
+
+The runner checks the remaining budget before commands, when it sleeps or polls, and after a verifier returns. A timed-out command is ambiguous and terminates the run. The station's reply is separate from the stop request. HTTP timeouts are socket bounds. Physical stop and command ordering after a network failure depend on the station.
+
+The unplug gate needs visual evidence of a cable clear of the hub. Rubric v4 requires a stack at least four inches tall that stands freely for three seconds after release. Current camera evidence and monitor prompts are proxies for the judge. Hardware validation needs a height reference and a check that the release and three-second dwell are visible.
+
+## Design selection
+
+The design review preferred a separate hierarchy with typed proof and action leases for a later version. The first slice keeps the existing runner because it already owns prompt changes, resets, and stop. The separate controller would need those paths extracted before it could run a match. This slice borrows explicit gate roles, an absolute clock, and separate abandonment and stop outcomes. It keeps generic plans and the legacy immediate `skip` behavior.
+
+## Evidence and next tests
+
+REFLECT uses observations around a failed subgoal to choose a bounded correction. Inner Monologue shows how false success can lead planning astray. LIBERO-RECOVER separates a retry from restoring a disrupted scene. Those distinctions map to stage verdicts, the authored recovery menu, and bounded abandonment. [REFLECT](https://proceedings.mlr.press/v229/liu23g.html) · [Inner Monologue](https://proceedings.mlr.press/v205/huang23c.html) · [LIBERO-RECOVER](https://arxiv.org/abs/2609.05178)
+
+IntervenGen supports labeling mistakes and their corrections separately in future demonstrations. FORGE uses estimated Cartesian contact force and an impedance controller. Gripper motor torque is a separate observation and needs a bench calibration before it can support any insertion judgement. [IntervenGen](https://doi.org/10.1109/IROS58592.2024.10801523) · [FORGE](https://doi.org/10.1109/LRA.2025.3551637)
+
+Sentinel supports comparing timestamped observations asynchronously. Hi Robot separates short task commands from the controller that executes them. Use a fake clock and scripted station to check that late verdicts never unlock another task, recovery consumes the stage budget, and optional failure preserves verified core progress. [Sentinel](https://proceedings.mlr.press/v270/agia25a.html) · [Hi Robot](https://www.pi.website/research/hirobot)
+
+## LiveKit
+
+Rubric v4 awards 10 points when the team shows its use of LiveKit to the referee before the match. The same rubric restricts human input after go, including voice. Keep tele-op handoffs in practice and demonstration collection. [Event page](https://luma.com/pah)
+
+For training, Portal can record synchronized observations, executed actions, and which operator supplied each action. Use the capture timeline to label the policy mistake, human correction, and recovery result. Verify the event's Metal/Dream adapter, feature schema, and Dream import against a recorded sample before relying on this path. The public Portal HITL tutorial uses a different arm and an ACT policy. [LiveKit Portal](https://github.com/livekit/portal) · [HITL reference](https://github.com/livekit-examples/portal-hitl)
+
+For detection, the optional LiveKit observer subscribes to named camera tracks and can run the existing monitor for a selected stage. It logs locally received frames and advisory verdicts. Comparing view coverage and detection latency with Dream debug trips requires paired recordings with a shared capture clock. The runner retains control and task advancement. [Robot camera tracks](https://docs.livekit.io/robotics/media/video/video-tracks/)

+"""Optional DimOS MCP viewer for the Hill Climb harness."""
+
+import argparse
+import base64
+import json
+from dataclasses import dataclass
+from typing import Any
+
+from dimos.agents.annotation import skill
+from dimos.agents.mcp.mcp_server import McpServer
+from dimos.core.coordination.blueprints import autoconnect
+from dimos.core.coordination.module_coordinator import ModuleCoordinator
+from dimos.core.module import Module, ModuleConfig
+
+from harness.frames import FrameSource, camera_matches
+from harness.station_client import StationClient
+
+
+@dataclass
+class WatcherSnapshot:
+    status: dict[str, Any]
+    images: dict[str, bytes]
+
+    def agent_encode(self) -> list[dict[str, Any]]:
+        """Encode the status and labelled JPEGs as MCP content blocks."""
+        content: list[dict[str, Any]] = [{"type": "text", "text": json.dumps(self.status)}]
+        for label, jpeg in self.images.items():
+            content.append({"type": "text", "text": label})
+            content.append({"type": "image", "mimeType": "image/jpeg",
+                            "data": base64.b64encode(jpeg).decode("ascii")})
+        return content
+
+
+class WatcherConfig(ModuleConfig):
+    station_url: str = "http://127.0.0.1:8091"
+    view_url: str = "http://127.0.0.1:8093"
+
+
+class HillClimbWatcher(Module):
+    config: WatcherConfig
+
+    @skill
+    def inspect_watcher(self, arm: str = "left") -> WatcherSnapshot:
+        """Show the overhead and selected wrist camera from the latest trip for the active prompt.
+
+        Use both images to judge whether the wrist camera sees the cable port from the side.
+        The arm argument is "left" or "right".
+        """
+        if arm not in ("left", "right"):
+            raise ValueError('arm must be "left" or "right"')
+
+        trip = FrameSource(self.config.view_url).latest_trip()
+        station = StationClient(self.config.station_url, timeout_s=5.0).status()
+        status = {k: station.get(k) for k in ("state", "prompt", "run", "chunks", "cameras")}
+        status["watch_arm"] = arm
+        if trip is None or station.get("state") != "running" or trip.prompt != station.get("prompt"):
+            status["reason"] = "No camera trip for the active prompt yet."
+            return WatcherSnapshot(status, {})
+
+        status["trip"] = trip.n
+        images = {}
+        for wanted in ("overhead", arm):
+            for role, jpeg in trip.frames.items():
+                if camera_matches(role, wanted):
+                    images["overhead" if wanted == "overhead" else f"{arm} wrist"] = jpeg
+                    break
+        status["views"] = list(images)
+        return WatcherSnapshot(status, images)
+
+
+def main() -> None:
+    parser = argparse.ArgumentParser(description=__doc__)
+    parser.add_argument("--station", default="http://127.0.0.1:8091", help="Dream station API URL")
+    parser.add_argument("--view", default="http://127.0.0.1:8093", help="Dream debug view URL")
+    parser.add_argument("--port", type=int, default=9990, help="loopback MCP port")
+    args = parser.parse_args()
+    blueprint = autoconnect(

+    ).global_config(viewer="none", serve_coordinator_rpc=False)
+    ModuleCoordinator.build(blueprint).loop()
+
+
+if __name__ == "__main__":
+    main()

+"""Sequential vs combined two-arm prompts for Dream-1, scored from MuJoCo ground truth (sim_station /objects).
+
+Each trial resets the scene, then runs one condition for the same total budget:
+
+  seq        left arm: apple -> bowl; switch the prompt to the right-arm task as soon as the apple is in
+             (or at the half-way mark), the way the harness advances stages
+  combined   one prompt naming both arms and both tasks
+  combined_free  one prompt with both tasks and no arm assignment
+
+Conditions are interleaved (seq, combined, combined_free, seq, ...) so model or network drift hits each equally.
+
+    python experiments/dual_arm_bench.py --trials 4 --budget 120 --out ../runs_dual_arm
+
+Needs sim_station.py running (--policy dream, or scripted for a dry check). Sim only: it calls /reset.
+"""
+
+from __future__ import annotations
+
+import argparse
+import json
+import math
+import sys
+import time
+import urllib.request
+from datetime import datetime, timezone
+from pathlib import Path
+
+sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
+from harness.frames import FrameSource  # noqa: E402
+
+LEFT_TASK = "with the left arm, put the apple in the bowl"
+RIGHT_TASK = "with the right arm, put the banana on the plate"
+PROMPTS = {
+    "combined": "with the left arm put the apple in the bowl while the right arm puts the banana on the plate, "
+                "both at the same time",
+    "combined_free": "put the apple in the bowl and the banana on the plate",
+}
+GOALS = {  # object, target, xy radius (m), max height above target origin (m), arm expected to do it
+    "apple_in_bowl": ("apple", "bowl", 0.06, 0.07, "left"),
+    "banana_on_plate": ("banana", "plate", 0.07, 0.05, "right"),
+}
+MOVING_MPS = 0.02  # a TCP faster than this counts as moving
+
+
+def call(base: str, method: str, route: str, body: dict | None = None, timeout: float = 30.0) -> dict:
+    data = None if body is None else json.dumps(body).encode()
+    req = urllib.request.Request(base + route, data=data, method=method, headers={"Content-Type": "application/json"})
+    with urllib.request.urlopen(req, timeout=timeout) as resp:
+        return json.loads(resp.read())
+
+
+def wait_state(base: str, states: tuple[str, ...], timeout: float) -> dict:
+    end = time.monotonic() + timeout
+    while time.monotonic() < end:
+        status = call(base, "GET", "/status")
+        if status["state"] in states:
+            return status
+        time.sleep(0.25)
+    raise TimeoutError(f"station never reached {states}")
+
+
+def goal_met(snap: dict, goal: str) -> bool:
+    obj, target, radius, height, _ = GOALS[goal]
+    o, t = snap["bodies"][obj], snap["bodies"][target]
+    return math.dist(o[:2], t[:2]) <= radius and o[2] - t[2] <= height
+
+
+def goal_dist(snap: dict, goal: str) -> float:
+    obj, target, *_ = GOALS[goal]
+    return math.dist(snap["bodies"][obj][:2], snap["bodies"][target][:2])
+
+
+def run_trial(base: str, view: FrameSource, condition: str, budget: float, out: Path, n: int) -> dict:
+    if call(base, "GET", "/status")["state"] not in ("idle", "error"):
+        call(base, "POST", "/stop")
+        wait_state(base, ("idle", "error"), 60)
+    call(base, "POST", "/reset", {})
+    wait_state(base, ("idle",), 60)
+    first = call(base, "GET", "/objects")
+    prompt = LEFT_TASK if condition == "seq" else PROMPTS[condition]
+    t0 = time.monotonic()
+    call(base, "POST", "/start", {"prompt": prompt})
+    samples, switched_at, done_at = [], None, {}
+    first_chunk_s = None
+    while (elapsed := time.monotonic() - t0) < budget:
+        snap = call(base, "GET", "/objects")
+        status = call(base, "GET", "/status")
+        if status["state"] == "error":
+            raise RuntimeError(f"station error: {status['last_error']}")
+        if first_chunk_s is None and status["chunks"] > 0:
+            first_chunk_s = round(elapsed, 1)
+        for goal in GOALS:
+            if goal not in done_at and goal_met(snap, goal):
+                done_at[goal] = round(elapsed, 1)
+        if condition == "seq" and switched_at is None and ("apple_in_bowl" in done_at or elapsed >= budget / 2):
+            call(base, "POST", "/prompt", {"prompt": RIGHT_TASK})
+            switched_at = round(elapsed, 1)
+        samples.append({"s": round(elapsed, 2), **snap})
+        time.sleep(0.25)
+    final = call(base, "GET", "/objects")
+    try:
+        trip = view.latest_trip(fallback=True)
+        if trip and "overhead" in trip.frames:
+            (out / f"trial{n:02d}_{condition}_end_overhead.jpg").write_bytes(trip.frames["overhead"])
+    except Exception as exc:  # frames are a nice-to-have
+        print(f"  (no end frame: {exc})", flush=True)
+    call(base, "POST", "/stop")
+    wait_state(base, ("idle", "error"), 60)
+
+    # Arm activity from TCP speed: how much each arm moved, and how often both moved at once.
+    moving = {"left": 0.0, "right": 0.0, "both": 0.0}
+    path = {"left": 0.0, "right": 0.0}
+    for a, b in zip(samples, samples[1:]):
+        dt = b["s"] - a["s"]
+        if dt <= 0:
+            continue
+        fast = {}
+        for side in ("left", "right"):
+            d = math.dist(a["tcp"][side], b["tcp"][side])
+            path[side] += d
+            fast[side] = d / dt > MOVING_MPS
+            moving[side] += dt if fast[side] else 0.0
+        moving["both"] += dt if fast["left"] and fast["right"] else 0.0
+    lift = {goal: round(max(s["bodies"][o][2] for s in samples) - first["bodies"][o][2], 3)
+            for goal, (o, *_rest) in GOALS.items()}
+    result = {
+        "trial": n, "condition": condition, "prompt": prompt, "budget_s": budget, "first_chunk_s": first_chunk_s,

+    def jpeg(self) -> bytes:
+        from PIL import Image

+        frame = self.event.frame
+        image = Image.frombytes("RGB", (frame.width, frame.height), bytes(frame.data))
+        # The SDK enumerates clockwise rotation in quarter turns.
+        if self.event.rotation:
+            image = image.rotate(-90 * int(self.event.rotation), expand=True)
+        buffer = io.BytesIO()
+        image.save(buffer, format="JPEG", quality=85)

+    def __init__(self, publisher: str, tracks: dict[str, str]):

+        from livekit import rtc
+

+    def _start_stream(self, track: rtc.RemoteVideoTrack, publication: rtc.RemoteTrackPublication,
+                      participant: rtc.RemoteParticipant) -> None:

+class Clock:
+    now = 0.0
+
+    def read(self):
+        return self.now
+
+    def sleep(self, seconds):
+        self.now += seconds
+

+class Station:
+    dry_run = False
+
+    def __init__(self, clock, *, stop_fails=False, ambiguous_prompt=None):
+        self.clock = clock
+        self.stop_fails = stop_fails
+        self.ambiguous_prompt = ambiguous_prompt
+        self.commands = []
+        self.state = "idle"
+        self.prompt = None
+
+    def status(self, *, timeout_s):
+        return {"state": self.state, "prompt": self.prompt, "arms": {}, "cameras": {}}
+
+    def start(self, prompt, checkpoint, *, timeout_s):
+        self.state = "running"
+        self.commands.append(("start", prompt, self.clock.read(), timeout_s))
+        self.prompt = prompt
+        return self.status(timeout_s=timeout_s)
+
+    def set_prompt(self, prompt, *, timeout_s):
+        self.commands.append(("prompt", prompt, self.clock.read(), timeout_s))
+        self.prompt = prompt
+        if prompt == self.ambiguous_prompt:
+            raise StationError(0, "prompt reply missing")
+        return self.status(timeout_s=timeout_s)
+
+    def stop(self, *, timeout_s):
+        self.commands.append(("stop", None, self.clock.read(), timeout_s))
+        if self.stop_fails:
+            raise StationError(0, "stop reply missing")
+        self.state = "idle"
+        return self.status(timeout_s=timeout_s)
+
+
+class Frames:
+    def latest(self, *, timeout_s):
+        return {"overhead": b"frame"}
+
+    def latest_trip(self, *, timeout_s):
+        return None

+def run(plan, tmp_path, verdicts, *, late=None, stop_fails=False, ambiguous_prompt=None):

+    class Judge:
+        def check(self, stage, frames, elapsed):

+
+    runner = Runner(plan, station, Frames(), {"monitor": Judge()}, RunLog(tmp_path / "runs"),
+                    clock=clock.read, sleep=clock.sleep)
