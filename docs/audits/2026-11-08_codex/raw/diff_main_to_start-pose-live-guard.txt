+## 2. Both arms at once
+
+The station API has **one prompt for one bimanual policy**. There is no per-arm command and no way to run two sessions. So "both arms at the same time" has to come from one of these:
+
+| Mode | How | Works today? | Use for |
+|---|---|---|---|
+| **A. One worker, the other parked (current).** | The right arm does everything; the left is parked by the reset prompt. | yes | default |
+| **B. Watcher.** | The stage's `watch:` puts one arm's wrist camera on the work, and the other arm works. The harness re-sends the park prompt if the watcher drifts (`watch_lost`). | partly: depends on Dream holding the watcher still (F5 says naming the arm is unreliable) | close views of the port, the ball in the gripper, the tower top |
+| **C. Combined prompt, two goals.** | "put the X … and the Y …" without naming arms; Dream assigns them. | 2/4 single-goal successes in the sim, both arms moving at once | parallel independent goals, e.g. ball + ball, once tested on Metal |
+| **D. Trained bimanual skill.** | Record teleop demos where the left arm watches or helps while the right works, under one fixed task text. | needs data | the only route to dependable two-arm behaviour |
+
+The harness can't make the two arms independent tasks. It **can** decide which mode each stage uses, which arm is the worker (section 3), and when a combined prompt is worth the risk. That decision gets a weight like the others (section 5).
+
+Experiment E1 (sim first, then station): 3 modes × 20 trials each on the same seeded scenes. Measure success, time to done, both-arms-moving seconds, and collisions or knocks. 20 per mode separates 30% from 70% success. A 0.5 vs 0.8 gap needs about 40 per mode for 80% power.

+## 3. Picking the arm from the layout
+
+What the harness has: the overhead camera, colour detector boxes (balls, cubes, sticks), cable-end boxes (new), gripper state, and joints (`/arms`, after a station restart).
+
+1. **Table frame.** One homography H from overhead pixels to table metres. Click the four table corners once per station (or mark them with tags) and store it in the plan. The arm bases `b_L` and `b_R` and the bin, hub and tower positions all go in that frame.
+2. **Cost of arm a for object o:**
+
+       c_a(o) = w_reach · ‖p_o − b_a‖ / R_a             reach, normalised by the arm's reach
+              + w_cross · 1[o is past the midline for a]   crossing the body
+              + w_clear · Σ_k exp(−d(path_a,o, k)² / σ²)   obstacles near the straight path: tower, hub, illegal balls
+              + w_busy  · 1[a holds something or is the watcher]
+              + w_skill · (1 − s_a(task))                  arm-specific skill prior: demos exist only for the right arm
+
+   Choose `a* = argmin_a c_a(o)`. If `c_a*(o) > c_max` for every arm, the object is unreachable: skip it or pick another object.
+3. **Turning the choice into an action.** F5 means naming the arm in the prompt is not enough on its own. In order of dependability:
+   - (i) choose the **object** the chosen arm is best placed for, and name it by colour and position ("the orange ball nearest the right arm"). Dream tends to use the nearer arm;
+   - (ii) for a fine-tune, record per-arm task texts ("… nearest the left arm" as well as "… nearest the right arm");
+   - (iii) the arm phrase as a hint only, and the monitor checks which arm moved. Count a wrong-arm move as a failed attempt.
+4. Experiment E2: does base Dream-1 on Metal pick the nearer arm? Place objects at 5 positions from left to right, 4 trials each, with and without an arm phrase. Log which arm moved first. The result sets `w_skill` and tells us whether (iii) is worth anything.

+## 4. Prompting Dream
+
+**Build on kaupau's `hybrid-harness` branch.** What it does that main doesn't:
+- **Templates with slots:** `tower_prompts` with `<piece>` / `<top>`, cable prompts as plan variables, and a `prompt_prefix` that is put back on every rewrite.
+- **Closed-loop rewriting:** the monitor returns `next_prompt` when it sees a wrong object or step, a plain stall, or a failure about to happen. The runner sends it, with a cooldown of 15 s and at most 3 per attempt. Every rewrite is logged as `prompt_rewrite`.
+- **Station lessons in the monitor's system prompt:** plugs are pulled straight up; carry a block high and lower it straight down; Dream ignores fine adjustments like "1 cm higher". There is also a running operator-lessons file, for testing only.
+- **`tools/label_rollout.py`:** labels Dream's own run records with stage, attempt, outcome and the clean task text. This is the bridge to fine-tune data.
+
+Formalised: the prompt is a policy `π_P(x) = template_s(slots(x))`, with `rewrite(x)` as a gated fallback. Slots come from the state estimate: object colour and position, arm (section 3), next tower piece, and which plug is next. A rewrite fires only when
+
+    g_rw = w_wrong·1[wrong object/step] + w_stall·(t − t_rise)/stall_s + w_risk·P(knock) − w_churn·n_rewrites  >  θ_rw
+    and  t − t_last_prompt ≥ τ_cool
+
+Hybrid's fixed rules are one point in this space: `θ_rw` = "the monitor chose to write one", τ_cool = 15, and a hard cap of 3.
+
+**Prompt experiments (E3).** The unit is one stage from a seeded scene, scored on success within T, time to first contact, and refusals.
+- Factors: specificity (generic task text vs colour + position), motion adverbs ("lift high, lower straight down"), arm phrase (none / hint), preamble (on / off, cables only), and length.
+- Plan: a fractional factorial screen in the YAM sim with real Dream-1, which is cheap. Then confirm the best 2-3 on Metal at 10-20 trials each.
+- Prompts already sent today, from the inference log, cover about 40 variants across 52 runs, but the log has no outcomes. Join them to harness `events.jsonl` with `label_rollout.py` to get a free first ranking.
+
+The fine-tune rule still holds. A fine-tune follows only its recorded texts, so whatever the base-model experiments settle on is what the teleop labels must say. Hybrid runs a fine-tune with `--no-rewrite` plus the recorded texts.

+## 5. The decision tree as weighted equations
+
+### 5.1 What the runner does today, as rules
+
+At each check (every `check_every_s` = 3 s), per stage attempt:
+- **done** if the verifier says done `confirm` (2) times in a row, or twice within `DONE_WINDOW_S` (15 s), or with `immediate` set;
+- **fail** if `failing` comes `confirm` times in a row and elapsed ≥ `FAIL_MIN_FRACTION` (0.5) × `timeout_s`; or progress drops by `REGRESSION_DROP` (0.3) below the attempt's max; or progress hasn't risen by `STALL_RISE` (0.05) for `stall_s`; or `timeout_s` passes, with one extension of `EXTEND_S` (20 s) while the gripper is on the target and `CONFIRM_GRACE_S` (10 s) while a done is pending;
+- **on fail:** abort, skip, or the recovery menu in order (`max_uses` each), then `home_and_retry` if allowed, up to `max_attempts`, never with less than `HOME_RESERVE_S` (30 s) left;
+- **guard trips** after `guard.confirm` illegal-ball answers (live: 3 distinct frames at 10 Hz), or when blind for `max_blind_s`.
+
+### 5.2 The same tree as equations
+
+State `x_t`: stage s, elapsed τ, time left `L = T − t`, the evidence features `φ(t)`, attempt count n, recovery uses, and the arm and object state.
+
+**Done evidence (log-odds, recursive):**
+
+    ℓ_t = γ · ℓ_{t−1} + Σ_i w_i · φ_i(t)
+
+| φ_i | Source | Today's implicit weight |
+|---|---|---|
+| monitor done (+1) / not (−1), × confidence | VLM | +1 / reset to 0 |
+| progress p_t (0..1) | VLM | used only for stall and regression |
+| gripper went from closed on an object to open, near the target | `/arms` | none (new) |
+| object at goal (detector box inside the bin or on the tower) | detector | none (new) |
+| plug count in the hub fell (cable-end boxes) | classifier | none (new) |
+| same frames as last time | sha1 | φ = 0 (not counted) |
+
+Done when `ℓ_t ≥ θ_done`. Today's rule is the special case γ = 1 on agreement and 0 on disagreement, `w_monitor = 1`, `θ_done = confirm = 2`.
+
+**Fail hazard:**
+
+    h_t = σ( b + w_f·n_fail + w_r·max(0, p_max − p_t − δ) + w_s·(τ − τ_rise)/stall_s + w_T·τ/timeout_s − w_on·1[on target] )
+
+The attempt ends when `h_t > θ_fail`. The hard rules above are the corners of this function: they fire when any one term is large.
+
+**Action choice when an attempt ends (or at each tick, for `continue`):** a ∈ {continue, re-prompt / rewrite, reset prompt, home + retry, skip, abort}.
+
+    Q(a | x) = P_a(succ within c_a) · V_s  +  W(L − c_a)  −  λ_risk · R_a
+
+- `V_s` = the stage's points (rubric v4: first cable +10, extra cable +5, tower pass +20, +3 per inch, ball +5), plus the value it unlocks (pass bars gate later stages).
+- `W(L)` = expected points from the stages after s with L seconds left. Compute it backwards over the stage list once per plan, using each stage's success-vs-time curve `F_s(τ)`.
+- `c_a` = time the action costs (re-prompt ~1 s, reset 5-20 s, home ~10 s plus `/start` 2.9 s).
+- `R_a` = risk: a DQ from a false done or a touch out of order, a knocked tower, an illegal ball.
+
+Pick `a* = argmax Q`. `on_fail: skip` and `max_attempts` become consequences of Q, not hand-set values.
+
+**Optimal timeout (replaces a fixed `timeout_s`):** keep going on stage s while the success rate per second, times its value, beats what the remaining time is worth elsewhere:
+
+    f_s(τ) / (1 − F_s(τ)) · V_s   ≥   dW/dL
+
+That gives each stage a timeout that depends on its own success curve and on how much match is left. Optional stages get short timeouts late in the match and longer ones early.
+
+### 5.3 The pass-bar constraint
+
+A false done on a pass bar (unplug, stack_2, stack_3, tower_pass) is a DQ. With per-look false-positive rate α for the evidence and k independent looks required, `P(false done) ≈ α^k`. Choose `θ_done` per stage so that `P(false done) ≤ ε` (e.g. 1%), then minimise the expected detection delay. This is the one hard constraint in the tuning. Everything else trades off in `J` below.
+
+### 5.4 Parameters and tuning
+
+θ = {w_i, γ, θ_done(s), w_f, w_r, w_s, w_T, w_on, θ_fail, λ_risk, θ_rw, w_wrong, w_churn, τ_cool, c_a weights (section 3), check period, live-guard Hz and frames, start-pose tolerance}. Today's constants (`confirm`, `STALL_RISE`, `REGRESSION_DROP`, `FAIL_MIN_FRACTION`, `DONE_WINDOW_S`, `EXTEND_S`, `CONFIRM_GRACE_S`, `HOME_RESERVE_S`, `SKIP_MIN_CONFIDENCE`, `REWRITE_*`) are its starting point.
+
+Objective, estimated in the stress sim and the rubric-v4 referee:
+
+    J(θ) = E[score] − μ · P(DQ) − ν · P(illegal ball)
+
+1. **Calibrate the sim's evidence model from real logs.** Per stage, how often the monitor says done when it's not, and the reverse (label saved frames by hand). Also the detector's miss and false-alarm rates, `F_s(τ)` from the runs, and refusal and IK-error rates. This is the STEP / SIMPLER warning: tuning against a sim with the wrong noise picks the wrong θ.
+2. **Search:** CMA-ES or coordinate hill climbing over θ. Use common random numbers (the same seeded scenes for every candidate), about 200 sim matches per candidate, run on the cluster.
+3. **Confirm on Metal:** the best 2 θ vs today's, 5 supervised matches each. Promote only if J is better and P(DQ) didn't rise.
+
+## 6. Ball handling
+
+Golf ball: 42.7 mm, rolls when nudged. The bin is white, the same colour as the illegal white ball. Dream does the grasp. The harness controls **which ball, from where, with what prompt, and whether the grasp worked**:
+
+1. **Choose the ball** (overhead detector + homography): legal colour; reachable by the chosen arm (section 3); clearance from the tower `d_tower ≥ 2·D_ball` and from any illegal ball `d_illegal ≥ 1.5·D_ball` so the gripper can't take both; not against an edge it can roll off. Score `s(b) = −c_a*(b) − w_tw·exp(−d_tower²/σ²) − w_il·exp(−d_illegal²/σ²)` and send the best: "pick up the orange ball nearest the right arm, straight down from above, and drop it into the white bin".
+2. **Grasp check, local and fast.** After the gripper closes, its opening g from `/arms` should sit in a band around the ball's width, `g ∈ [g_ball − δ, g_ball + δ]`, for N ticks. Fully closed means a miss; wider means it's on something else. This is the same idea as hybrid's "closed fully on nothing" sensor rule. Calibrate `g_ball` once by closing on a ball.
+3. **Rolled away:** if the target's overhead position jumps by more than D_ball between frames without being held, re-target with a new prompt naming the ball's new position. Don't retry blind.
+4. **The illegal ball:** the live guard (10 Hz, `/stop` in under 0.5 s) stays as the hard stop. The ball choice in step 1 lowers the chance it's ever needed.
+5. **Dream's own ball skill:** there are no ball demos yet; balls rely on base Dream-1. To make it dependable, record ball teleop (top-down grasp, carry high, release over the bin) under one fixed text, and add one demo set starting next to the white ball so the policy learns to go around it.
+

+STD = np.array([0.229, 0.224, 0.225], np.float32)
+
+
+@dataclass
+class End:
+    label: str            # usb_c | usb_a
+    prob: float
+    x0: float
+    y0: float
+    x1: float
+    y1: float             # fractions of the image
+
+
+def ferrules(bgr: np.ndarray, work_w: int = WORK_W) -> list[dict]:
+    """Candidate ferrules: [{cx, cy, side}] in the input image's pixels (side = crop side)."""
+    h0, w0 = bgr.shape[:2]
+    s = work_w / w0
+    im = cv2.resize(bgr, (work_w, max(1, round(h0 * s))), interpolation=cv2.INTER_AREA)
+    hsv = cv2.cvtColor(im, cv2.COLOR_BGR2HSV)
+    H, S, V = hsv[..., 0], hsv[..., 1], hsv[..., 2]
+    mask = ((H >= 3) & (H <= 22) & (S >= 110) & (V >= 60)).astype(np.uint8)
+    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, np.ones((3, 3), np.uint8))
+    n, lab, stats, _ = cv2.connectedComponentsWithStats(mask)
+    total = im.shape[0] * im.shape[1]
+    out = []
+    for i in range(1, n):
+        area = int(stats[i, cv2.CC_STAT_AREA])
+        if area < 30 or area > 0.08 * total:
+            continue
+        ys, xs = np.nonzero(lab == i)
+        (cx, cy), (w, h), _ = cv2.minAreaRect(np.stack([xs, ys], 1).astype(np.float32))
+        L, W = max(w, h), max(1.0, min(w, h))
+        if L / W > 4.0 or area / max(L * W, 1.0) < 0.5:
+            continue
+        out.append({"cx": cx / s, "cy": cy / s, "side": max(L * CROP_SCALE, 24) / s})
+    return out
+
+
+def crop(bgr: np.ndarray, cand: dict, size: int = SIZE) -> np.ndarray:
+    side = cand["side"]
+    x0, y0 = cand["cx"] - side / 2, cand["cy"] - side / 2
+    M = np.float32([[size / side, 0, -x0 * size / side], [0, size / side, -y0 * size / side]])
+    return cv2.warpAffine(bgr, M, (size, size), flags=cv2.INTER_AREA, borderMode=cv2.BORDER_REPLICATE)
+
+
+def _prep(crops: list[np.ndarray]) -> np.ndarray:
+    x = np.stack([c[:, :, ::-1].astype(np.float32) / 255.0 for c in crops])
+    return ((x - MEAN) / STD).transpose(0, 3, 1, 2).copy()
+
+
+class CableEndClassifier:
+    def __init__(self, model_path: str | Path, min_prob: float = 0.7, max_candidates: int = 24):
+        self.net = cv2.dnn.readNetFromONNX(str(model_path))
+        self.min_prob = min_prob
+        self.max_candidates = max_candidates
+
+    def _forward(self, x: np.ndarray) -> np.ndarray:
+        """Always the same input shape, padded: OpenCV 5.0's DNN kills the process when one net is reused with a
+        batch larger than an earlier one (2, 5, 4, 4, then 16 crashed it, 7 Nov). Chunks of BATCH cost ~2.5 ms."""
+        out = []
+        for k in range(0, len(x), BATCH):
+            chunk = x[k:k + BATCH]
+            pad = np.zeros((BATCH,) + x.shape[1:], np.float32)
+            pad[:len(chunk)] = chunk
+            self.net.setInput(pad)
+            out.append(self.net.forward()[:len(chunk)].copy())
+        return np.concatenate(out)
+
+    def ends(self, bgr: np.ndarray) -> list[End]:
+        cands = ferrules(bgr)[: self.max_candidates]
+        if not cands:
+            return []
+        logits = self._forward(_prep([crop(bgr, c) for c in cands]))
+        e = np.exp(logits - logits.max(1, keepdims=True))
+        probs = e / e.sum(1, keepdims=True)
+        h, w = bgr.shape[:2]
+        out = []
+        for c, p in zip(cands, probs):
+            k = int(p.argmax())
+            if LABELS[k] == "none" or p[k] < self.min_prob:
+                continue
+            half = c["side"] / 2.6 * 0.75     # box around the ferrule and tip, not the whole crop
+            out.append(End(LABELS[k], float(p[k]), max(0, c["cx"] - half) / w, max(0, c["cy"] - half) / h,
+                           min(w, c["cx"] + half) / w, min(h, c["cy"] + half) / h))
+        return out
+
+    def ends_jpeg(self, jpeg: bytes) -> list[End]:
+        bgr = cv2.imdecode(np.frombuffer(jpeg, np.uint8), cv2.IMREAD_COLOR)
+        return [] if bgr is None else self.ends(bgr)
+
+    def annotate(self, jpeg: bytes) -> bytes:
+        bgr = cv2.imdecode(np.frombuffer(jpeg, np.uint8), cv2.IMREAD_COLOR)
+        if bgr is None:
+            return jpeg
+        found = self.ends(bgr)
+        if not found:
+            return jpeg
+        h, w = bgr.shape[:2]
+        th = max(2, w // 300)
+        for e in found:
+            col = (255, 0, 255) if e.label == "usb_c" else (0, 200, 255)   # magenta = USB-C, amber = USB-A
+            p0, p1 = (int(e.x0 * w), int(e.y0 * h)), (int(e.x1 * w), int(e.y1 * h))
+            cv2.rectangle(bgr, p0, p1, col, th)
+            cv2.putText(bgr, f"{NAMES[e.label]} {e.prob:.2f}", (p0[0], max(12, p0[1] - 4)), 0,
+                        max(0.4, w / 1600), col, max(1, th // 2))
+        ok, buf = cv2.imencode(".jpg", bgr, [cv2.IMWRITE_JPEG_QUALITY, 88])
+        return buf.tobytes() if ok else jpeg
+
+    @staticmethod
+    def legend() -> str:
+        return ("MAGENTA boxes = USB-C end of a cable, AMBER boxes = USB-A end (the end that plugs into the power "
+                "strip's USB ports); from a local classifier, can miss or mislabel.")
+
+
+def main(argv: list[str] | None = None) -> int:
+    import argparse
+    ap = argparse.ArgumentParser(description="label cable ends in images")
+    ap.add_argument("model")
+    ap.add_argument("images", nargs="+")
+    ap.add_argument("--out-dir", default=None)
+    a = ap.parse_args(argv)
+    clf = CableEndClassifier(a.model)

+        if a.out_dir:
+            Path(a.out_dir).mkdir(parents=True, exist_ok=True)
+            (Path(a.out_dir) / (Path(p).stem + "_ends.jpg")).write_bytes(clf.annotate(data))
+    return 0
+
+

+    raise SystemExit(main())

+"""The runner's decision tree as weighted equations, so its constants can be tuned (HARNESS_DECISION_MODEL section 5).
+
+Three pieces, all pure functions of numbers (no I/O, no clock):
+
+1. Done evidence, a running score over looks:  l_t = keep * l_{t-1} + sum_i w_i * phi_i(t),  done when l_t >= theta.
+   With DEFAULT weights it is exactly the runner's rule: `confirm` monitor "done" looks in a row pass the stage, a
+   "not done" look resets the count, a repeated look at the same frames counts for nothing, and a second "done"
+   within done_window_s passes even with a "failing" flicker in between.
+2. Fail score:  F = combine_k(w_k * g_k), each g_k a ratio that reaches 1 when today's hard rule fires
+   (consecutive failing looks / confirm, consecutive "stalled" looks / confirm, time since progress rose / stall_s,
+   elapsed / timeout_s). A look is failing on a no, a "failing" status, or progress falling REGRESSION_DROP below
+   the attempt's best (look_failing). The attempt fails when F >= theta_fail. combine="max" is today's tree (any one rule);
+   combine="sum" lets weak signals add up, which is what tuning can explore.
+3. Value of the time left:  W_i(L) = max_T  F_i(T) (V_i + W_{i+1}(L - t_succ)) + (1 - F_i(T)) * [skip ? W_{i+1}(L - T) : 0]
+   over a stage list, by dynamic programming on a 1 s grid. It gives each stage the timeout that maximises expected
+   points for the time left (`plan_timeouts`) and the value of an action (`action_value`):
+   Q(a) = P_a * V_s + W(L - c_a) - risk_weight * R_a.
+
+Nothing here moves a robot or changes the runner yet: the runner keeps its own rules. The tests check that the
+default weights reproduce them; tuning and shadow logging come next.
+"""
+
+from __future__ import annotations
+
+import math
+from dataclasses import dataclass, field, replace
+from typing import Iterable, Sequence
+
+# Today's runner constants (harness/runner.py), the starting point for tuning.
+CONFIRM = 2
+DONE_WINDOW_S = 15.0
+REGRESSION_DROP = 0.3
+FAIL_MIN_FRACTION = 0.5
+
+
+# --------------------------------------------------------------------------------------------- 1. done evidence
+@dataclass(frozen=True)
+class DoneWeights:
+    w_monitor: float = 1.0          # a monitor "done" look
+    w_sensor_release: float = 0.0   # gripper went from closed on an object to open near the target (/arms); new, off
+    w_goal_box: float = 0.0         # detector sees the object at its goal (in the bin, on the tower); new, off
+    w_plug_count: float = 0.0       # cable-end boxes: one fewer plug in the strip; new, off
+    keep: float = 1.0               # share of the score carried to the next look when nothing argues against it
+    reset_on_no: bool = True        # a "not done" / "failing" look sets the score to 0 (outside the done window)
+    theta: float = float(CONFIRM)   # done when the score reaches this
+    window_s: float = DONE_WINDOW_S  # a second "done" within this passes, flickers in between notwithstanding
+
+
+@dataclass(frozen=True)
+class Look:
+    """One check. done: the verifier's answer (True / False / None = no answer). failing: monitor status failing."""
+    t: float
+    done: bool | None
+    failing: bool = False
+    same_frames: bool = False       # the same camera images as the previous done look
+    monitor: bool = True            # from the monitor: a look with no done answer still resets the count
+    sensor_release: float = 0.0     # 0..1 features from the fast sensors
+    goal_box: float = 0.0
+    plug_count: float = 0.0
+
+
+@dataclass
+class DoneState:
+    score: float = 0.0
+    last_done_t: float | None = None
+
+
+def done_step(state: DoneState, look: Look, w: DoneWeights = DoneWeights()) -> tuple[DoneState, bool]:
+    """Folds one look into the done score. Returns (new state, stage passes now)."""
+    fast = w.w_sensor_release * look.sensor_release + w.w_goal_box * look.goal_box + w.w_plug_count * look.plug_count
+    if look.done is True and look.same_frames:
+        return DoneState(state.score * w.keep + fast, state.last_done_t), state.score * w.keep + fast >= w.theta
+    if look.done is True:
+        recent = state.last_done_t is not None and look.t - state.last_done_t <= w.window_s
+        score = state.score * w.keep + w.w_monitor + fast
+        return DoneState(score, look.t), score >= w.theta or recent
+    # The runner: a no / failing look right after a done (within the window) changes nothing; otherwise it resets the
+    # count. A monitor look with no done answer resets it even inside the window (the window still passes the next done).
+    flicker = look.done is False or look.failing
+    blank = look.done is None and look.monitor
+    in_window = state.last_done_t is not None and look.t - state.last_done_t <= w.window_s
+    if flicker and in_window:
+        score = state.score
+    elif (flicker or blank) and w.reset_on_no:
+        score = fast
+    elif flicker or blank:
+        score = state.score * w.keep + fast
+    else:
+        score = state.score * w.keep + fast
+    return DoneState(score, state.last_done_t), score >= w.theta
+
+
+def run_looks(looks: Iterable[Look], w: DoneWeights = DoneWeights()) -> float | None:
+    """Time of the look that passes the stage, or None."""
+    st = DoneState()
+    for lk in looks:
+        st, ok = done_step(st, lk, w)
+        if ok:
+            return lk.t
+    return None

+# ----------------------------------------------------------------------------------------------- 2. fail score
+@dataclass(frozen=True)
+class FailWeights:
+    w_fail: float = 1.0          # consecutive failing looks / confirm (monitor: only after min_fraction of the timeout)
+    w_stalled: float = 1.0       # consecutive "stalled" monitor looks / confirm (stages with a stall window)
+    w_stall: float = 1.0         # seconds since progress last rose / stall_s
+    w_time: float = 1.0          # elapsed / timeout_s
+    w_on_target: float = 0.0     # subtracted while a gripper holds the target (today: a one-off 20 s extension)
+    w_regress: float = 1.0       # in look_failing: (max progress - progress) / regress_drop >= 1 makes a failing look
+    confirm: int = CONFIRM
+    regress_drop: float = REGRESSION_DROP
+    min_fraction: float = FAIL_MIN_FRACTION
+    combine: str = "max"         # "max" = today's tree (any rule fires); "sum" = weak signals add up
+    theta: float = 1.0
+
+
+def look_failing(done: bool | None, status_failing: bool, progress: float | None, max_progress: float | None,
+                 done_seen: bool, w: FailWeights = FailWeights()) -> bool:
+    """Is one look a failing look? The verifier said no, the monitor said failing, or progress fell regress_drop
+    below the attempt's best (not counted once a done has been seen, as in the runner)."""
+    regress = 0.0
+    if progress is not None and max_progress is not None and not done_seen:
+        regress = w.w_regress * max(0.0, max_progress - progress) / w.regress_drop
+    return done is False or status_failing or regress >= 1.0 - 1e-9
+
+
+@dataclass(frozen=True)
+class AttemptState:
+    elapsed: float
+    timeout_s: float
+    consec_fail: int = 0                 # failing looks in a row (look_failing)
+    consec_stalled: int = 0              # "stalled" monitor looks in a row
+    since_rise_s: float | None = None    # seconds since progress last rose by STALL_RISE (None: no progress yet)
+    stall_s: float | None = None         # the stage's stall window (None: no stall rules)
+    monitor: bool = True                 # failing looks come from the monitor (then min_fraction applies)
+    on_target: bool = False
+
+
+def fail_terms(a: AttemptState, w: FailWeights = FailWeights()) -> dict[str, float]:
+    """Each term reaches its weight when its hard rule would fire on its own."""
+    gate_ok = not a.monitor or a.elapsed >= w.min_fraction * a.timeout_s
+    terms = {"fail": w.w_fail * (a.consec_fail / w.confirm) if gate_ok else 0.0,
+             "time": w.w_time * a.elapsed / a.timeout_s}
+    if a.stall_s is not None:
+        terms["stalled"] = w.w_stalled * a.consec_stalled / w.confirm
+        if a.since_rise_s is not None:
+            terms["stall"] = w.w_stall * a.since_rise_s / a.stall_s
+    return terms
+
+
+def fail_score(a: AttemptState, w: FailWeights = FailWeights()) -> float:
+    terms = list(fail_terms(a, w).values())
+    s = max(terms) if w.combine == "max" else sum(terms)
+    return s - (w.w_on_target if a.on_target else 0.0)
+
+
+def attempt_fails(a: AttemptState, w: FailWeights = FailWeights()) -> bool:
+    return fail_score(a, w) >= w.theta - 1e-9
+
+
+# -------------------------------------------------------------------------------- 3. value of the time left
+@dataclass(frozen=True)
+class StageModel:
+    """One stage for planning. Success by time tau: F(tau) = p_max * (1 - exp(-max(0, tau - t_min) / tau_c)).
+    `gate`: a pass bar; if it fails, nothing after it scores (it is retried until the clock instead of skipped).
+    Fit p_max, t_min, tau_c per stage from run logs or the stress sim."""
+    name: str
+    value: float
+    p_max: float
+    tau_c: float
+    t_min: float = 0.0
+    gate: bool = False
+
+    def F(self, tau: float) -> float:
+        if tau <= self.t_min:
+            return 0.0
+        return self.p_max * (1.0 - math.exp(-(tau - self.t_min) / self.tau_c))
+
+    def mean_success_time(self, T: float, step: float = 1.0) -> float:
+        """Expected time spent given success by T (integral of tau dF over [0, T] / F(T))."""
+        FT = self.F(T)
+        if FT <= 0:
+            return T
+        n = max(1, int(T / step))
+        acc, prev = 0.0, 0.0
+        for k in range(1, n + 1):
+            tau = k * T / n
+            f = self.F(tau)
+            acc += (tau - T / n / 2) * (f - prev)
+            prev = f
+        return acc / FT
+
+
+@dataclass
+class Plan:
+    """W[i][L]: expected points from stage i on with L whole seconds left; best_T[i][L]: that stage's timeout."""
+    stages: Sequence[StageModel]
+    horizon_s: int
+    W: list[list[float]] = field(default_factory=list)
+    best_T: list[list[int]] = field(default_factory=list)
+
+    def value(self, i: int, left_s: float) -> float:
+        if i >= len(self.stages):
+            return 0.0
+        return self.W[i][max(0, min(self.horizon_s, int(left_s)))]
+
+    def timeout(self, i: int, left_s: float) -> int:
+        return self.best_T[i][max(0, min(self.horizon_s, int(left_s)))]
+
+
+def plan_timeouts(stages: Sequence[StageModel], horizon_s: int, step_s: int = 1) -> Plan:
+    """Backward DP over the stage list. For a gate stage a failure leaves 0 (nothing later scores)."""
+    n = len(stages)
+    W = [[0.0] * (horizon_s + 1) for _ in range(n + 1)]
+    best = [[0] * (horizon_s + 1) for _ in range(n)]
+    for i in range(n - 1, -1, -1):
+        st = stages[i]
+        succ_t = [st.mean_success_time(T) for T in range(horizon_s + 1)]
+        for L in range(horizon_s + 1):
+            top, top_T = W[i + 1][L], 0           # T = 0: skip the stage
+            for T in range(step_s, L + 1, step_s):
+                p = st.F(T)
+                after_ok = W[i + 1][max(0, L - int(round(succ_t[T])))]
+                after_fail = 0.0 if st.gate else W[i + 1][L - T]
+                v = p * (st.value + after_ok) + (1 - p) * after_fail

+"""Is the robot starting a stage from a pose the policy was trained to start from?
+
+VLAs lose more to an unfamiliar start pose than to anything else measured in LIBERO-Plus (arXiv 2510.13626,
+OpenVLA-OFT: robot initial state -59.9 points, camera -37.4, language -15.6). A fine-tune only saw the starts in
+its teleop episodes. The reference (tools/start_poses.py) is the first frame of every task segment in those
+episodes, keyed by the exact task text, which v4 prompts match byte for byte.
+
+Joint state comes from GET /arms `positions_rad` (station add-on; works while idle) or else from the newest
+debug-view trip's observation `state.left_arm` / `state.right_arm` (only while a run is going).
+Grippers are not compared: open or closed both occur at every start in the data.
+"""
+
+from __future__ import annotations
+
+import json
+from dataclasses import dataclass
+from pathlib import Path
+from typing import Any
+
+SIDES = ("left", "right")
+
+
+@dataclass
+class PoseCheck:
+    status: str                    # ok | far | no_reference | no_state
+    distance: dict[str, float]     # per arm: max |joint - reference| (rad) to the nearest reference start
+    nearest: str | None            # the reference episode it was nearest to
+    source: str | None             # where the joint state came from
+    joints: dict[str, list[float]] | None
+
+    def as_event(self) -> dict[str, Any]:
+        return {"status": self.status, "distance_rad": {k: round(v, 3) for k, v in self.distance.items()},
+                "nearest": self.nearest, "source": self.source,
+                "joints": {k: [round(x, 3) for x in v] for k, v in (self.joints or {}).items()}}
+
+
+class StartPoses:
+    """prompt -> list of {"left": [6 rad], "right": [6 rad], "episode": "dataset/episode/segment"}."""
+
+    def __init__(self, by_prompt: dict[str, list[dict[str, Any]]]):
+        self.by_prompt = by_prompt
+
+    @classmethod
+    def load(cls, path: str | Path) -> StartPoses:
+        data = json.loads(Path(path).read_text(encoding="utf-8"))
+        by = data.get("by_prompt") if isinstance(data, dict) else None
+        if not isinstance(by, dict):
+            raise ValueError(f"{path}: expected {{'by_prompt': {{prompt: [start, ...]}}}}")
+        return cls(by)
+
+    def nearest(self, prompt: str, joints: dict[str, list[float]]) -> tuple[dict[str, float], str | None]:
+        """Per-arm distance to the reference start that is nearest overall (the larger of the two arm distances)."""
+        best: tuple[float, dict[str, float], str | None] | None = None
+        for ref in self.by_prompt.get(prompt, []):
+            d = {s: _linf(joints[s], ref[s]) for s in SIDES if s in joints and s in ref}
+            if not d:
+                continue
+            worst = max(d.values())
+            if best is None or worst < best[0]:
+                best = (worst, d, ref.get("episode"))
+        return (best[1], best[2]) if best else ({}, None)
+
+    def check(self, prompt: str, joints: dict[str, list[float]] | None, tolerance_rad: float,
+              source: str | None = None) -> PoseCheck:
+        if prompt not in self.by_prompt:
+            return PoseCheck("no_reference", {}, None, source, joints)
+        if not joints:
+            return PoseCheck("no_state", {}, None, source, joints)
+        dist, ep = self.nearest(prompt, joints)
+        if not dist:
+            return PoseCheck("no_state", {}, None, source, joints)
+        status = "ok" if max(dist.values()) <= tolerance_rad else "far"
+        return PoseCheck(status, dist, ep, source, joints)
+
+
+def _linf(a: list[float], b: list[float]) -> float:
+    n = min(len(a), len(b))
+    return max((abs(float(a[i]) - float(b[i])) for i in range(n)), default=0.0)
+
+
+def joints_from_arms(arms: dict[str, Any]) -> dict[str, list[float]] | None:
+    """{side: [rad]} from GET /arms when the add-on reports positions_rad."""
+    out = {}
+    for side in SIDES:
+        q = (arms or {}).get(side, {}).get("positions_rad") if isinstance((arms or {}).get(side), dict) else None
+        if isinstance(q, list) and q:
+            out[side] = [float(x) for x in q]
+    return out or None
+
+
+def joints_from_observation(obs: dict[str, Any] | None) -> dict[str, list[float]] | None:

+    out = {}

+        q = (obs or {}).get(f"state.{side}_arm")
+        if isinstance(q, list) and q and all(isinstance(x, (int, float)) for x in q):
+            out[side] = [float(x) for x in q]
+    return out or None

+CONFIRM, WINDOW = 2, 15.0

+def runner_done(looks):
+    """The done branch of Runner._watch, transcribed (frames always present, no immediate verdicts)."""
+    consec_done, last_done_t = 0, None
+    for lk in looks:
+        failing = lk.done is False or lk.failing
+        if lk.done is True and lk.same_frames:
+            continue
+        if lk.done is True:
+            consec_done += 1
+            recent = last_done_t is not None and lk.t - last_done_t <= WINDOW
+            last_done_t = lk.t
+            if consec_done >= CONFIRM or recent:
+                return lk.t
+        elif failing and last_done_t is not None and lk.t - last_done_t <= WINDOW:
+            pass
+        elif failing:
+            consec_done = 0
+        elif lk.done is not None or lk.monitor:
+            consec_done = 0
+    return None
+
+
+def random_looks(rng):
+    t, out, have_done = 0.0, [], False
+    for _ in range(rng.randint(1, 14)):
+        t += rng.choice([1.0, 3.0, 3.0, 6.0, 12.0, 20.0])
+        done = rng.choice([True, True, False, None])
+        out.append(Look(t, done, failing=rng.random() < 0.2, same_frames=have_done and done is True and rng.random() < 0.3,
+                        monitor=rng.random() < 0.8))
+        have_done = have_done or done is True
+    return out
+

+def power_strip(M, face_at, side):
+    """Black power strip whose long side face (the USB ports) is at face_at, facing `side` (horizontal unit).
+    Returns (along unit vector, strip height)."""
+    L, W, H = rng.uniform(0.18, 0.3), rng.uniform(0.045, 0.06), rng.uniform(0.03, 0.045)
+    box = rbox("strip", (L, W, H), 0.004, M["strip"])
+    c = face_at - side * (W / 2)
+    box.location = (c.x + side.y * rng.uniform(-0.3, 0.3) * L, c.y - side.x * rng.uniform(-0.3, 0.3) * L, H / 2)
+    box.rotation_euler = (0, 0, math.atan2(side.x, -side.y))
+    bpy.context.view_layer.update()
+    return Vector((-side.y, side.x, 0)), H

+def yaw_for(d):

+    return math.atan2(-d.x, d.y)

+def distractors(M, centre, n):

+def rbox(name, size, bevel, m):

+def stadium(name, w, h, length, m):

+    o = rbox(name, (w, length, h), h * 0.49, m)

+def build_end(kind, M):
+    """One plug + ferrule + strain relief, along +Y from the origin (relief at y<0, tip at y>0). Returns
+    (parent empty, tip centre local, ferrule centre local, ferrule length)."""
+    parts = []
+    if kind == "a":
+        fw, fh, fl = 13.0, 7.0, 19.0
+        tw, th, tl = 12.0, 4.5, 12.0

+    fer.location = (0, fl / 2 * MM, 0)

+            win = rbox("win", (2.0 * MM, 2.5 * MM, 0.3 * MM), 0, M["dark"])

+            parts.append(win)

+        slot.location = (0, (fl + tl + 0.05) * MM, 0)
+        parts += [shell, slot]

+        rib = bpy.context.object
+        rib.rotation_euler = (math.pi / 2, 0, 0)
+        rib.location = (0, -(1.0 + k * 2.1) * MM, 0)
+        rib.data.materials.append(M["black"])
+        parts.append(rib)
+    bpy.ops.mesh.primitive_cylinder_add(radius=2.2 * MM, depth=15 * MM, vertices=24)
+    core = bpy.context.object
+    core.rotation_euler = (math.pi / 2, 0, 0)
+    core.location = (0, -7.5 * MM, 0)
+    core.data.materials.append(M["orange_rubber"])
+    parts.append(core)
+    root = bpy.data.objects.new(f"end_{kind}", None)
+    bpy.context.collection.objects.link(root)
+    for p in parts:
+        p.parent = root
+    tip = Vector((0, (fl + tl * 0.5) * MM, 0))
+    return root, tip, Vector((0, fl / 2 * MM, 0)), fl * MM

+def cable_curve(p0, d0, p1, d1, M):
+    """Orange cable from the C relief end to the A relief end: a Bezier with tangents along each end's axis."""
+    cu = bpy.data.curves.new("cable", "CURVE")
+    cu.dimensions = "3D"
+    cu.bevel_depth = 2.0 * MM
+    cu.bevel_resolution = 4
+    sp = cu.splines.new("BEZIER")
+    sp.bezier_points.add(1)
+    k = (p1 - p0).length * rng.uniform(0.3, 0.6)
+    for bp, p, d, sign in ((sp.bezier_points[0], p0, d0, -1), (sp.bezier_points[1], p1, d1, -1)):
+        bp.co = p
+        bp.handle_left_type = bp.handle_right_type = "FREE"
+        bp.handle_right = p + d * sign * k * (1 if bp is sp.bezier_points[0] else -1)
+        bp.handle_left = p - (bp.handle_right - p)
+    o = bpy.data.objects.new("cable", cu)
+    bpy.context.collection.objects.link(o)
+    o.data.materials.append(M["orange_rubber"])
+    return o

+def kelvin(t):
+    t = t / 100.0
+    r = 1.0 if t <= 66 else min(1.0, 1.29 * (t - 60) ** -0.133)
+    g = min(1.0, (0.39 * math.log(t) - 0.63)) if t <= 66 else min(1.0, 1.13 * (t - 60) ** -0.0755)
+    b = 1.0 if t >= 66 else (0.0 if t <= 19 else min(1.0, 0.543 * math.log(t - 10) - 1.19))
+    return (max(r, 0), max(g, 0), max(b, 0))

+def seen(sc, cam, tgt, root):
+    """Line of sight from the camera to the target: for an end, the first thing hit must be part of that end (or
+    nothing before it); for 'none', the camera must not be inside or right against an object."""
+    dg = bpy.context.evaluated_depsgraph_get()
+    o = cam.matrix_world.translation
+    if sc.ray_cast(dg, o, Vector((0, 0, 1)), distance=1.0)[0]:
+        return False     # something right above the camera: it is inside an object (the strip, the ball)
+    v = tgt - o
+    dist = v.length
+    hit, loc, _, _, obj, _ = sc.ray_cast(dg, o, v.normalized(), distance=dist * 1.2)
+    if not hit:
+        return root is None
+    if root is None:
+        return (loc - o).length > 0.4 * dist
+    return obj.parent == root or (loc - o).length > dist * 0.97

+def prep(bgr: np.ndarray) -> np.ndarray:
+    """BGR uint8 (any size) -> CHW float32 normalised, SIZE x SIZE. The harness does the same in numpy."""
+    im = cv2.resize(bgr, (SIZE, SIZE), interpolation=cv2.INTER_AREA)[:, :, ::-1].astype(np.float32) / 255.0
+    return ((im - MEAN) / STD).transpose(2, 0, 1).copy()

+def augment(bgr: np.ndarray, rng: random.Random, synth: bool) -> np.ndarray:
+    h, w = bgr.shape[:2]
+    # zoom/shift/rotate: the runtime crop is centred on a detected ferrule but not perfectly
+    z = rng.uniform(0.75, 1.35) if synth else rng.uniform(0.85, 1.15)
+    ang = rng.uniform(-180, 180)
+    M = cv2.getRotationMatrix2D((w / 2 + rng.uniform(-0.1, 0.1) * w, h / 2 + rng.uniform(-0.1, 0.1) * h), ang, z)
+    bgr = cv2.warpAffine(bgr, M, (w, h), borderMode=cv2.BORDER_REFLECT)
+    if rng.random() < 0.5:
+        bgr = cv2.flip(bgr, 1)
+    hsv = cv2.cvtColor(bgr, cv2.COLOR_BGR2HSV).astype(np.float32)
+    hsv[..., 0] = (hsv[..., 0] + rng.uniform(-4, 4)) % 180
+    hsv[..., 1] *= rng.uniform(0.5, 1.3)
+    hsv[..., 2] *= rng.uniform(0.6, 1.4)
+    bgr = cv2.cvtColor(np.clip(hsv, 0, 255).astype(np.uint8), cv2.COLOR_HSV2BGR)
+    # the wrist cameras: small, soft, compressed. Shrink to a random low res and back, blur, JPEG.
+    if synth or rng.random() < 0.3:
+        lo = rng.randint(24, 96)
+        bgr = cv2.resize(cv2.resize(bgr, (lo, lo), interpolation=cv2.INTER_AREA), (w, h))
+    if rng.random() < 0.4:
+        k = rng.choice([3, 5])
+        bgr = cv2.GaussianBlur(bgr, (k, k), 0)
+    if rng.random() < 0.3:   # motion blur

+def model():
+    m = torchvision.models.mobilenet_v3_small(weights=torchvision.models.MobileNet_V3_Small_Weights.DEFAULT)
+    m.classifier[3] = nn.Linear(m.classifier[3].in_features, len(LABELS))

+def train(items, epochs, dev, seed=0):
+    torch.manual_seed(seed)
+    m = model().to(dev)
+    counts = np.bincount([y for _, y, _ in items], minlength=len(LABELS)).astype(np.float32)
+    w = torch.tensor(counts.sum() / np.maximum(counts, 1) / len(LABELS), device=dev)
+    dl = torch.utils.data.DataLoader(DS(items, True, seed), batch_size=128, shuffle=True, num_workers=0)
+    opt = torch.optim.AdamW(m.parameters(), lr=1e-3, weight_decay=1e-4)
+    sched = torch.optim.lr_scheduler.OneCycleLR(opt, 1e-3, total_steps=epochs * len(dl))
+    lossf = nn.CrossEntropyLoss(weight=w, label_smoothing=0.05)
+    for ep in range(epochs):
+        m.train()
+        tot = n = 0
+        for x, y in dl:
+            x, y = x.to(dev), y.to(dev)
+            loss = lossf(m(x), y)
+            opt.zero_grad()
+            loss.backward()
+            opt.step()
+            sched.step()
+            tot += loss.item() * len(y)
+            n += len(y)
+        print(f"  epoch {ep + 1}/{epochs} loss {tot / n:.3f}", flush=True)
+    return m.eval()

+@torch.no_grad()

+    ds = DS(items, False)
+    xs = torch.stack([ds[i][0] for i in range(len(ds))])
+    out = []
+    for k in range(0, len(xs), 256):
+        out.append(torch.softmax(m(xs[k:k + 256].to(dev)), 1).cpu().numpy())
+    return np.concatenate(out) if out else np.zeros((0, len(LABELS)))

+def report(name, probs, ys):
+    pred = probs.argmax(1)

+    for t, p in zip(ys, pred):
+        cm[t, p] += 1
+    print("   true\\pred " + " ".join(f"{l:>6}" for l in LABELS))
+    for t in range(3):
+        print(f"   {LABELS[t]:>9} " + " ".join(f"{cm[t, p]:>6}" for p in range(3)))
+    for k, l in enumerate(LABELS):
+        tp = cm[k, k]
+        prec = tp / max(cm[:, k].sum(), 1)
+        rec = tp / max(cm[k].sum(), 1)
+        print(f"   {l}: precision {prec:.2f} recall {rec:.2f} (n={cm[k].sum()})")
+    return cm

+def at_threshold(probs, ys, t):
+    """What the harness does: report an end only when its class prob >= t (else nothing)."""
+    pred = probs.argmax(1)

+        tp = int((said & (ys == k)).sum())
+        print(f"   at p>={t}: {l} precision {tp / max(int(said.sum()), 1):.2f} recall {tp / max(int((ys == k).sum()), 1):.2f}"
+              f" ({int(said.sum())} reported)")

+"""Fit each stage's success-vs-time curve from run logs, for harness.decide's planner.
+
+    python tools/fit_stage_curves.py RUNS_DIR [RUNS_DIR ...] [--out plans/stage_curves.json] [--horizon 295]
+
+Reads every segments.jsonl under the given directories. One episode = one stage in one run: the time from its
+first attempt's start to the end of its first successful attempt (recoveries and retries included), or, if it
+never succeeded, the total time spent on it (censored: we only know it took longer than that).
+
+Model (harness.decide.StageModel): F(tau) = p_max * (1 - exp(-(tau - t_min) / tau_c)) for tau > t_min. Fitted by
+maximum likelihood on a grid, with censoring: a success at tau adds log f(tau), a censored episode at c adds
+log(1 - F(c)). Stage names are grouped by stripping trailing digits and underscores (ball_1..ball_8 -> ball).
+
+Caveat: most logs so far are from Dream's MuJoCo YAM sim, not the Metal station. Fit station logs separately
+before trusting the timeouts for a match.
+"""
+
+from __future__ import annotations
+
+import argparse
+import json
+import math
+import sys
+from collections import defaultdict
+from pathlib import Path
+
+sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
+from harness.decide import StageModel, plan_timeouts  # noqa: E402
+
+GRID_P = [i / 50 for i in range(1, 51)]
+GRID_TAU = [2.0 * 1.12 ** k for k in range(45)]          # 2 s .. ~330 s
+
+
+def episodes(dirs: list[Path]) -> dict[str, list[tuple[float, bool]]]:
+    """stage group -> [(time, succeeded)]"""
+    out: dict[str, list[tuple[float, bool]]] = defaultdict(list)
+    for d in dirs:
+        for seg_file in d.rglob("segments.jsonl"):
+            runs: dict[str, list[dict]] = defaultdict(list)
+            for line in seg_file.read_text(encoding="utf-8", errors="replace").splitlines():
+                try:
+                    r = json.loads(line)
+                except json.JSONDecodeError:
+                    continue
+                if r.get("t_start") is None or r.get("t_end") is None:
+                    continue
+                runs[r["stage"]].append(r)
+            for name, segs in runs.items():
+                segs.sort(key=lambda r: r["t_start"])
+                t0 = segs[0]["t_start"]
+                ok = next((r for r in segs if r.get("kind") == "stage" and r.get("outcome") == "ok"), None)
+                if ok is not None:
+                    out[group(name)].append((ok["t_end"] - t0, True))
+                else:
+                    out[group(name)].append((max(r["t_end"] for r in segs) - t0, False))
+    return out
+
+
+def group(name: str) -> str:
+    return name.rstrip("0123456789").rstrip("_") or name
+
+
+def loglik(eps: list[tuple[float, bool]], p: float, tau: float, tmin: float) -> float:
+    ll = 0.0
+    for t, ok in eps:
+        if ok:
+            if t <= tmin:
+                return -math.inf
+            ll += math.log(p) - (t - tmin) / tau - math.log(tau)
+        else:
+            F = 0.0 if t <= tmin else p * (1 - math.exp(-(t - tmin) / tau))
+            ll += math.log(max(1e-12, 1 - F))
+    return ll
+
+
+def fit(eps: list[tuple[float, bool]]) -> tuple[float, float, float, float]:
+    """(p_max, tau_c, t_min, loglik)"""
+    succ = [t for t, ok in eps if ok]
+    tmins = [0.0] if not succ else sorted({0.0, *(round(min(succ) * f, 2) for f in (0.25, 0.5, 0.75, 0.95))})
+    best = (0.0, GRID_TAU[0], 0.0, -math.inf)
+    for tmin in tmins:
+        for p in GRID_P:
+            for tau in GRID_TAU:
+                ll = loglik(eps, p, tau, tmin)
+                if ll > best[3]:
+                    best = (p, tau, tmin, ll)
+    return best
+
+
+def main(argv: list[str] | None = None) -> int:
+    ap = argparse.ArgumentParser(description=__doc__.splitlines()[0])
+    ap.add_argument("dirs", nargs="+", type=Path)
+    ap.add_argument("--out", type=Path, default=None)
+    ap.add_argument("--min-episodes", type=int, default=5)
+    a = ap.parse_args(argv)
+    eps = episodes(a.dirs)
+    fitted = {}
+    print(f"{'stage':<24}{'n':>5}{'ok':>5}{'p_max':>8}{'tau_c s':>9}{'t_min s':>9}  median ok s")
+    for name, e in sorted(eps.items()):
+        if len(e) < a.min_episodes:
+            continue
+        p, tau, tmin, _ = fit(e)
+        succ = sorted(t for t, ok in e if ok)
+        med = f"{succ[len(succ) // 2]:.1f}" if succ else "-"
+        print(f"{name:<24}{len(e):>5}{len(succ):>5}{p:>8.2f}{tau:>9.1f}{tmin:>9.1f}  {med}")
+        fitted[name] = {"p_max": p, "tau_c": round(tau, 2), "t_min": tmin, "episodes": len(e), "successes": len(succ)}
+    if a.out:
+        a.out.write_text(json.dumps(fitted, indent=1) + "\n", encoding="utf-8")
+        print("wrote", a.out)
+    return 0
+
+
+def models(curves: dict, spec: list[tuple[str, str, float, bool]]) -> list[StageModel]:
+    """[(stage name, curve group, points, gate)] -> StageModels for plan_timeouts."""
+    out = []
+    for name, grp, value, gate in spec:
+        c = curves[grp]
+        out.append(StageModel(name, value, c["p_max"], c["tau_c"], c["t_min"], gate))
+    return out
+
+
+if __name__ == "__main__":
+    raise SystemExit(main())

+"""Build the start-pose reference for harness.start_pose from LeRobot teleop datasets.
+
+    python tools/start_poses.py OUT.json DATASET_DIR [DATASET_DIR ...]
+
+For every episode, the first frame of each task segment (a change of task_index starts a segment) becomes one
+reference start under that task's exact text. observation.state is [left 6 joints, left gripper, right 6 joints,
+right gripper] (the Metal/YAM follower layout in meta/info.json); grippers are dropped. Needs pyarrow.
+"""
+
+from __future__ import annotations
+
+import json
+import sys
+from pathlib import Path
+
+
+def segment_starts(dataset: Path) -> list[tuple[str, dict]]:
+    import pyarrow.parquet as pq  # noqa: PLC0415 - only this tool needs it
+
+    info = json.loads((dataset / "meta" / "info.json").read_text(encoding="utf-8"))
+    names = info["features"]["observation.state"]["names"]
+    idx = {side: [names.index(f"{side}_joint_{j}") for j in range(6)] for side in ("left", "right")}
+    tasks = {}
+    for line in (dataset / "meta" / "tasks.jsonl").read_text(encoding="utf-8").splitlines():
+        if line.strip():
+            t = json.loads(line)
+            tasks[t["task_index"]] = t["task"]
+    out = []
+    for f in sorted((dataset / "data").glob("chunk-*/episode_*.parquet")):
+        cols = pq.read_table(f, columns=["observation.state", "task_index"]).to_pydict()
+        prev, seg = None, 0
+        for state, ti in zip(cols["observation.state"], cols["task_index"]):
+            if ti != prev:
+                start = {side: [round(float(state[i]), 4) for i in ids] for side, ids in idx.items()}
+                start["episode"] = f"{dataset.name}/{f.stem}/seg{seg}"
+                out.append((tasks[ti], start))
+                prev, seg = ti, seg + 1
+    return out
+
+
+def main(argv: list[str]) -> int:
+    if len(argv) < 2:
+        print(__doc__)
+        return 2
+    by: dict[str, list[dict]] = {}
+    for d in argv[1:]:
+        for task, start in segment_starts(Path(d)):
+            by.setdefault(task, []).append(start)
+    Path(argv[0]).write_text(json.dumps({"by_prompt": by}, indent=1) + "\n", encoding="utf-8")
+    for task, starts in by.items():
+        print(f"{len(starts):3d}  {task}")
+    return 0
+
+
+if __name__ == "__main__":
+    raise SystemExit(main(sys.argv[1:]))
